# 🎬 Real-Time Movie Analytics Pipeline

A real-time streaming analytics pipeline built using Apache Kafka, Apache Spark, and Apache NiFi for processing and analyzing movie rating data.

---

## 🚀 Technologies Used

- Apache Kafka
- Apache Spark
- Apache NiFi
- Python
- Java
- SQL

---

## 📊 Features

- Real-time movie data streaming
- Kafka producers for ratings and movies data
- Stream processing using Spark
- Data ingestion and flow management using NiFi
- Aggregation and analytics processing

---

## 📁 Project Structure

```bash
KafkaExcelProducers/
Nifi/
aggregation_analysis.py
kafka_stream_reader.py
non_aggregation_analysis.py
```
